# Storico delle valutazioni dell'estrattore NLP

Regola del progetto: le regole di `nlp_extract.py` si tarano solo sul **dev set**.
Il **test set** si valuta una volta sola. Il **gold set** è stato usato per analizzare gli errori
e quindi non è più un test indipendente.

## Versione 1 (regole iniziali)

Valutata su dataset sintetico (ottimistico) e poi su gold set (primo test indipendente).

| Campo | Gold (v1) accuratezza | Gold (v1) F1 macro |
|---|---|---|
| Piano | 1.00 | n.d. |
| Tipo di edificio | 0.74 | 0.84 |
| Sostanze pericolose | 0.93 | 0.93 |
| Persone | 0.76 | 0.82 |
| Meteo | 0.77 | 0.84 |

Baseline sul dev set (v1): tipo di edificio 0.57, sostanze 0.90, persone 0.67, meteo 0.70.

## Versione 2 (dopo correzioni sul dev set)

Correzioni: sinonimi per edifici (casa, palazzo, villetta, officina, magazzino, fabbrica),
sostanze (benzina, GPL, idrogeno, ossigeno, cloro, propano, tanica), negazioni ("non c'è / non ci sono"),
assenze e incertezza espresse in più modi, meteo calmo ("aria ferma", "tempo stabile", "non tira vento").

| Insieme | Tipo di edificio | Sostanze | Persone | Meteo | Note |
|---|---|---|---|---|---|
| Dev (usato per tarare) | 1.00 | 1.00 | 1.00 | 1.00 | Non è un test: è l'insieme di correzione |
| Gold (contaminato) | 0.99 | 0.98 | 0.98 | 1.00 | Gli errori del gold hanno guidato le parole aggiunte: non indipendente |
| **Test (una sola valutazione)** | **1.00** | **1.00** | **0.97** | **1.00** | 1 errore su 30 testi: "Non ci sono persone dentro" → non riconosciuto |

## Limiti da dichiarare nella documentazione

- Tutti i testi (dev, gold, test) sono stati scritti dallo stesso autore: l'assistente. Il test set
  non è quindi indipendente dal modo di scrivere delle regole. Un test vero richiederebbe testi scritti
  da persone diverse, ad esempio colleghi o compagni di corso.
- Il test set contiene 30 testi: è piccolo, e ogni errore sposta le metriche di circa 3 punti.
- Il risultato sul test set non è stato usato per correggere la regola residua (persone assenti).

# Storico delle valutazioni dell'estrattore NLP

Regola del progetto: le regole di `nlp_extract.py` si tarano solo sul **dev set**.
Il **test set** si valuta una volta sola. Il **gold set** è stato usato per analizzare gli errori
e quindi non è più un test indipendente.

## Versione 1 (regole iniziali)

Valutata su dataset sintetico (ottimistico) e poi su gold set (primo test indipendente).

| Campo | Gold (v1) accuratezza | Gold (v1) F1 macro |
|---|---|---|
| Piano | 1.00 | n.d. |
| Tipo di edificio | 0.74 | 0.84 |
| Sostanze pericolose | 0.93 | 0.93 |
| Persone | 0.76 | 0.82 |
| Meteo | 0.77 | 0.84 |

Baseline sul dev set (v1): tipo di edificio 0.57, sostanze 0.90, persone 0.67, meteo 0.70.

## Versione 2 (dopo correzioni sul dev set)

Correzioni: sinonimi per edifici (casa, palazzo, villetta, officina, magazzino, fabbrica),
sostanze (benzina, GPL, idrogeno, ossigeno, cloro, propano, tanica), negazioni ("non c'è / non ci sono"),
assenze e incertezza espresse in più modi, meteo calmo ("aria ferma", "tempo stabile", "non tira vento").

| Insieme | Tipo di edificio | Sostanze | Persone | Meteo | Note |
|---|---|---|---|---|---|
| Dev (usato per tarare) | 1.00 | 1.00 | 1.00 | 1.00 | Non è un test: è l'insieme di correzione |
| Gold (contaminato) | 0.99 | 0.98 | 0.98 | 1.00 | Gli errori del gold hanno guidato le parole aggiunte: non indipendente |
| **Test (una sola valutazione)** | **1.00** | **1.00** | **0.97** | **1.00** | 1 errore su 30 testi: "Non ci sono persone dentro" → non riconosciuto |

## Limiti da dichiarare nella documentazione

- Tutti i testi (dev, gold, test) sono stati scritti dallo stesso autore: l'assistente. Il test set
  non è quindi indipendente dal modo di scrivere delle regole. Un test vero richiederebbe testi scritti
  da persone diverse, ad esempio colleghi o compagni di corso.
- Il test set contiene 30 testi: è piccolo, e ogni errore sposta le metriche di circa 3 punti.
- Il risultato sul test set non è stato usato per correggere la regola residua (persone assenti).

# Storico delle valutazioni dell'estrattore NLP

Regola del progetto: le regole di `nlp_extract.py` si tarano solo sul **dev set**.
Il **test set** si valuta una volta sola. Il **gold set** è stato usato per analizzare gli errori
e quindi non è più un test indipendente.

## Versione 1 (regole iniziali)

Valutata su dataset sintetico (ottimistico) e poi su gold set (primo test indipendente).

| Campo | Gold (v1) accuratezza | Gold (v1) F1 macro |
|---|---|---|
| Piano | 1.00 | n.d. |
| Tipo di edificio | 0.74 | 0.84 |
| Sostanze pericolose | 0.93 | 0.93 |
| Persone | 0.76 | 0.82 |
| Meteo | 0.77 | 0.84 |

Baseline sul dev set (v1): tipo di edificio 0.57, sostanze 0.90, persone 0.67, meteo 0.70.

## Versione 2 (dopo correzioni sul dev set)

Correzioni: sinonimi per edifici (casa, palazzo, villetta, officina, magazzino, fabbrica),
sostanze (benzina, GPL, idrogeno, ossigeno, cloro, propano, tanica), negazioni ("non c'è / non ci sono"),
assenze e incertezza espresse in più modi, meteo calmo ("aria ferma", "tempo stabile", "non tira vento").

| Insieme | Tipo di edificio | Sostanze | Persone | Meteo | Note |
|---|---|---|---|---|---|
| Dev (usato per tarare) | 1.00 | 1.00 | 1.00 | 1.00 | Non è un test: è l'insieme di correzione |
| Gold (contaminato) | 0.99 | 0.98 | 0.98 | 1.00 | Gli errori del gold hanno guidato le parole aggiunte: non indipendente |
| **Test (una sola valutazione)** | **1.00** | **1.00** | **0.97** | **1.00** | 1 errore su 30 testi: "Non ci sono persone dentro" → non riconosciuto |

## Limiti da dichiarare nella documentazione

- Tutti i testi (dev, gold, test) sono stati scritti dallo stesso autore: l'assistente. Il test set
  non è quindi indipendente dal modo di scrivere delle regole. Un test vero richiederebbe testi scritti
  da persone diverse, ad esempio colleghi o compagni di corso.
- Il test set contiene 30 testi: è piccolo, e ogni errore sposta le metriche di circa 3 punti.
- Il risultato sul test set non è stato usato per correggere la regola residua (persone assenti).

# Storico delle valutazioni dell'estrattore NLP

Regola del progetto: le regole di `nlp_extract.py` si tarano solo sul **dev set**.
Il **test set** si valuta una volta sola. Il **gold set** è stato usato per analizzare gli errori
e quindi non è più un test indipendente.

## Versione 1 (regole iniziali)

Valutata su dataset sintetico (ottimistico) e poi su gold set (primo test indipendente).

| Campo | Gold (v1) accuratezza | Gold (v1) F1 macro |
|---|---|---|
| Piano | 1.00 | n.d. |
| Tipo di edificio | 0.74 | 0.84 |
| Sostanze pericolose | 0.93 | 0.93 |
| Persone | 0.76 | 0.82 |
| Meteo | 0.77 | 0.84 |

Baseline sul dev set (v1): tipo di edificio 0.57, sostanze 0.90, persone 0.67, meteo 0.70.

## Versione 2 (dopo correzioni sul dev set)

Correzioni: sinonimi per edifici (casa, palazzo, villetta, officina, magazzino, fabbrica),
sostanze (benzina, GPL, idrogeno, ossigeno, cloro, propano, tanica), negazioni ("non c'è / non ci sono"),
assenze e incertezza espresse in più modi, meteo calmo ("aria ferma", "tempo stabile", "non tira vento").

| Insieme | Tipo di edificio | Sostanze | Persone | Meteo | Note |
|---|---|---|---|---|---|
| Dev (usato per tarare) | 1.00 | 1.00 | 1.00 | 1.00 | Non è un test: è l'insieme di correzione |
| Gold (contaminato) | 0.99 | 0.98 | 0.98 | 1.00 | Gli errori del gold hanno guidato le parole aggiunte: non indipendente |
| **Test (una sola valutazione)** | **1.00** | **1.00** | **0.97** | **1.00** | 1 errore su 30 testi: "Non ci sono persone dentro" → non riconosciuto |

## Limiti da dichiarare nella documentazione

- Tutti i testi (dev, gold, test) sono stati scritti dallo stesso autore: l'assistente. Il test set
  non è quindi indipendente dal modo di scrivere delle regole. Un test vero richiederebbe testi scritti
  da persone diverse, ad esempio colleghi o compagni di corso.
- Il test set contiene 30 testi: è piccolo, e ogni errore sposta le metriche di circa 3 punti.
- Il risultato sul test set non è stato usato per correggere la regola residua (persone assenti).

# Storico delle valutazioni dell'estrattore NLP

Regola del progetto: le regole di `nlp_extract.py` si tarano solo sul **dev set**.
Il **test set** si valuta una volta sola. Il **gold set** è stato usato per analizzare gli errori
e quindi non è più un test indipendente.

## Versione 1 (regole iniziali)

Valutata su dataset sintetico (ottimistico) e poi su gold set (primo test indipendente).

| Campo | Gold (v1) accuratezza | Gold (v1) F1 macro |
|---|---|---|
| Piano | 1.00 | n.d. |
| Tipo di edificio | 0.74 | 0.84 |
| Sostanze pericolose | 0.93 | 0.93 |
| Persone | 0.76 | 0.82 |
| Meteo | 0.77 | 0.84 |

Baseline sul dev set (v1): tipo di edificio 0.57, sostanze 0.90, persone 0.67, meteo 0.70.

## Versione 2 (dopo correzioni sul dev set)

Correzioni: sinonimi per edifici (casa, palazzo, villetta, officina, magazzino, fabbrica),
sostanze (benzina, GPL, idrogeno, ossigeno, cloro, propano, tanica), negazioni ("non c'è / non ci sono"),
assenze e incertezza espresse in più modi, meteo calmo ("aria ferma", "tempo stabile", "non tira vento").

| Insieme | Tipo di edificio | Sostanze | Persone | Meteo | Note |
|---|---|---|---|---|---|
| Dev (usato per tarare) | 1.00 | 1.00 | 1.00 | 1.00 | Non è un test: è l'insieme di correzione |
| Gold (contaminato) | 0.99 | 0.98 | 0.98 | 1.00 | Gli errori del gold hanno guidato le parole aggiunte: non indipendente |
| **Test (una sola valutazione)** | **1.00** | **1.00** | **0.97** | **1.00** | 1 errore su 30 testi: "Non ci sono persone dentro" → non riconosciuto |

## Limiti da dichiarare nella documentazione

- Tutti i testi (dev, gold, test) sono stati scritti dallo stesso autore: l'assistente. Il test set
  non è quindi indipendente dal modo di scrivere delle regole. Un test vero richiederebbe testi scritti
  da persone diverse, ad esempio colleghi o compagni di corso.
- Il test set contiene 30 testi: è piccolo, e ogni errore sposta le metriche di circa 3 punti.
- Il risultato sul test set non è stato usato per correggere la regola residua (persone assenti).

# Storico delle valutazioni dell'estrattore NLP

Regola del progetto: le regole di `nlp_extract.py` si tarano solo sul **dev set**.
Il **test set** si valuta una volta sola. Il **gold set** è stato usato per analizzare gli errori
e quindi non è più un test indipendente.

## Versione 1 (regole iniziali)

Valutata su dataset sintetico (ottimistico) e poi su gold set (primo test indipendente).

| Campo | Gold (v1) accuratezza | Gold (v1) F1 macro |
|---|---|---|
| Piano | 1.00 | n.d. |
| Tipo di edificio | 0.74 | 0.84 |
| Sostanze pericolose | 0.93 | 0.93 |
| Persone | 0.76 | 0.82 |
| Meteo | 0.77 | 0.84 |

Baseline sul dev set (v1): tipo di edificio 0.57, sostanze 0.90, persone 0.67, meteo 0.70.

## Versione 2 (dopo correzioni sul dev set)

Correzioni: sinonimi per edifici (casa, palazzo, villetta, officina, magazzino, fabbrica),
sostanze (benzina, GPL, idrogeno, ossigeno, cloro, propano, tanica), negazioni ("non c'è / non ci sono"),
assenze e incertezza espresse in più modi, meteo calmo ("aria ferma", "tempo stabile", "non tira vento").

| Insieme | Tipo di edificio | Sostanze | Persone | Meteo | Note |
|---|---|---|---|---|---|
| Dev (usato per tarare) | 1.00 | 1.00 | 1.00 | 1.00 | Non è un test: è l'insieme di correzione |
| Gold (contaminato) | 0.99 | 0.98 | 0.98 | 1.00 | Gli errori del gold hanno guidato le parole aggiunte: non indipendente |
| **Test (una sola valutazione)** | **1.00** | **1.00** | **0.97** | **1.00** | 1 errore su 30 testi: "Non ci sono persone dentro" → non riconosciuto |

## Limiti da dichiarare nella documentazione

- Tutti i testi (dev, gold, test) sono stati scritti dallo stesso autore: l'assistente. Il test set
  non è quindi indipendente dal modo di scrivere delle regole. Un test vero richiederebbe testi scritti
  da persone diverse, ad esempio colleghi o compagni di corso.
- Il test set contiene 30 testi: è piccolo, e ogni errore sposta le metriche di circa 3 punti.
- Il risultato sul test set non è stato usato per correggere la regola residua (persone assenti).

# Storico delle valutazioni dell'estrattore NLP

Regola del progetto: le regole di `nlp_extract.py` si tarano solo sul **dev set**.
Il **test set** si valuta una volta sola. Il **gold set** è stato usato per analizzare gli errori
e quindi non è più un test indipendente.

## Versione 1 (regole iniziali)

Valutata su dataset sintetico (ottimistico) e poi su gold set (primo test indipendente).

| Campo | Gold (v1) accuratezza | Gold (v1) F1 macro |
|---|---|---|
| Piano | 1.00 | n.d. |
| Tipo di edificio | 0.74 | 0.84 |
| Sostanze pericolose | 0.93 | 0.93 |
| Persone | 0.76 | 0.82 |
| Meteo | 0.77 | 0.84 |

Baseline sul dev set (v1): tipo di edificio 0.57, sostanze 0.90, persone 0.67, meteo 0.70.

## Versione 2 (dopo correzioni sul dev set)

Correzioni: sinonimi per edifici (casa, palazzo, villetta, officina, magazzino, fabbrica),
sostanze (benzina, GPL, idrogeno, ossigeno, cloro, propano, tanica), negazioni ("non c'è / non ci sono"),
assenze e incertezza espresse in più modi, meteo calmo ("aria ferma", "tempo stabile", "non tira vento").

| Insieme | Tipo di edificio | Sostanze | Persone | Meteo | Note |
|---|---|---|---|---|---|
| Dev (usato per tarare) | 1.00 | 1.00 | 1.00 | 1.00 | Non è un test: è l'insieme di correzione |
| Gold (contaminato) | 0.99 | 0.98 | 0.98 | 1.00 | Gli errori del gold hanno guidato le parole aggiunte: non indipendente |
| **Test (una sola valutazione)** | **1.00** | **1.00** | **0.97** | **1.00** | 1 errore su 30 testi: "Non ci sono persone dentro" → non riconosciuto |

## Limiti da dichiarare nella documentazione

- Tutti i testi (dev, gold, test) sono stati scritti dallo stesso autore: l'assistente. Il test set
  non è quindi indipendente dal modo di scrivere delle regole. Un test vero richiederebbe testi scritti
  da persone diverse, ad esempio colleghi o compagni di corso.
- Il test set contiene 30 testi: è piccolo, e ogni errore sposta le metriche di circa 3 punti.
- Il risultato sul test set non è stato usato per correggere la regola residua (persone assenti).

==> ./README.md <==
# SO-VVF-NEXT

Sistema basato su conoscenza per il dispatch dei mezzi in una sala operativa dei Vigili del Fuoco.
Progetto d'esame di Ingegneria della Conoscenza (ICON), Università di Bari. Dati interamente sintetici.

## Problema

Dato un insieme di incidenti attivi e una flotta di mezzi distribuiti in stazioni, scegliere quale mezzo assegnare a ciascun incidente:
- solo tra i mezzi **idonei** (regole Prolog su tipo di intervento, equipaggiamento e gravità);
- minimizzando il **tempo totale di percorrenza** (distanze da una griglia con ostacoli).

## Architettura

1. **Dati** (`src/generate_dataset.py`): chiamate strutturate con valori veri. Il modulo `src/nlp_extract.py` è un **adattatore di ingresso** che ricava i campi dal testo; non è oggetto di valutazione nella relazione.
2. **Knowledge base Prolog** (`knowledge_base/kb.pl`, interrogata via `pyswip`): idoneità dei mezzi, definizione della gravità a tre livelli, regole ricorsive (propagazione del pericolo tra strutture adiacenti), negazione per fallimento (`\+`) per incompatibilità tra mezzi e sostanze, abduzione sulle possibili cause.
3. **Ricerca nello spazio degli stati** (`src/search.py`):
   - **Stato**: insieme degli incidenti già assegnati, con il mezzo assegnato a ciascuno.
   - **Azione**: assegnare un mezzo idoneo e ancora libero a un incidente non ancora servito.
   - **Stato iniziale**: nessun incidente assegnato.
   - **Obiettivo**: tutti gli incidenti assegnati.
   - **Costo**: somma dei tempi di percorrenza.
   - **Algoritmi confrontati**: BFS e UCS (non informate) contro A* (informata).
4. **Euristica per A\*, da problema rilassato**: si rimuove l'ordine delle assegnazioni e si mantiene l'esclusività dei mezzi. Il costo ottimo dell'assegnamento dei rimanenti incidenti ai mezzi liberi (algoritmo ungherese, `scipy.optimize.linear_sum_assignment`) è un limite inferiore del costo reale, quindi h è **ammissibile**. È **consistente**: assegnare un incidente non può far calare h più del costo dell'azione stessa. Come confronto si usa anche una versione più debole, il minimo per incidente, da cui la sovrastima del numero di nodi espansi.
5. **Rete bayesiana** (`src/bayes_engine.py`): 8 nodi con CPT stimate per massima verosimiglianza con pseudoconteggi di Laplace. Produce la probabilità di gravità critica, usata come feature.
6. **Machine learning** (`src/train_models.py`): classificazione della gravità a tre livelli con **nested cross-validation** (esterna per la stima, interna per la scelta degli iperparametri). Esperimento A: feature grezze. Esperimento B: feature aggiunte dalla KB e dalla rete bayesiana. Risultati come media ± deviazione standard.

## Decisioni di progetto

- **Gravità a tre livelli** (critico, alto, basso), definita da regole Prolog dichiarate.
- **Nessun reasoner OWL.** La rappresentazione è relazionale in Prolog. La corrispondenza con una tassonomia di concetti è descritta nella documentazione, senza implementazione OWL.
- **CSP** formulato come assegnazione: variabili = incidenti, domini = mezzi idonei forniti da Prolog, vincolo = esclusività del mezzo. È risolto dalla ricerca nello spazio degli stati.
- **NLP** limitato all'adattatore di ingresso. Le sue prove restano in `results/` come controllo di funzionamento, non come risultato del progetto.
- **Esclusi**: clustering (non utile, i dati sono già classificati) e reti neurali (fuori dal nucleo del programma).

## Vincoli delle linee guida

- Nessuna matrice di confusione di un singolo run: le metriche ML sono medie ± deviazione standard da nested CV.
- Parametri documentati e motivati: pseudoconteggi di Laplace, numero di fold, dimensioni della griglia e degli scenari, in `config.py`.
- Complessità della KB misurata e riportata: numero di regole, predicati e profondità della ricorsione.

"""Generatore di chiamate al 115 sintetiche con valori veri dei campi.

Ogni record contiene un testo in italiano parlato (con rumore: minuscole,
riempitivi, abbreviazioni, punteggiatura assente) e i valori veri dei campi.
nlp_extract.py dovrà ricavare i campi dal solo testo; i valori veri servono
solo a validate.py per misurare l'accuratezza dell'estrazione.

"""

import csv
import random
import re
import sys
from collections import Counter
from pathlib import Path


ROOT = Path(__file__).resolve().parents[1]
sys.path.insert(0, str(ROOT))
sys.path.insert(0, str(ROOT / "src"))

import config 

from domain import (  
    PAROLE_CHIAVE,
    Campo,
    Meteo,
    Persone,
    SostanzePericolose,
    TipoEdificio,
)

ORDINALI = {1: "primo", 2: "secondo", 3: "terzo", 4: "quarto", 5: "quinto", 6: "sesto"}

APERTURE = [
    "Pronto, c'è",
    "Salve, abbiamo",
    "Qui c'è",
    "Sono sul posto, c'è",
    "Segnalo",
    "Buongiorno, c'è",
]

# Frasi per il meteo: il valore vero è in Meteo, la frase è solo il modo di dirlo.
FRASI_METEO = {
    Meteo.VENTO_FORTE: ["c'è vento forte", "il vento è forte"],
    Meteo.CALMO: ["non c'è vento", "il tempo è calmo"],
}

RIEMPITIVI = ["eh", "ehm", "cioè", "allora"]


def _frase_edificio(rng: random.Random, edificio: TipoEdificio, piano: int) -> str:
    kw = rng.choice(PAROLE_CHIAVE[Campo.TIPO_EDIFICIO][edificio])
    if edificio is TipoEdificio.BOSCO:
        return f"un incendio in {kw}"
    return f"un incendio in {kw} al {ORDINALI[piano]} piano"


def _frase_sostanze(rng: random.Random, sostanze: SostanzePericolose) -> str:
    kw = rng.choice(PAROLE_CHIAVE[Campo.SOSTANZE_PERICOLOSE][sostanze])
    if sostanze is SostanzePericolose.SI:
        return f"vicino alle fiamme ci sono {kw}"
    return kw


def _frase_persone(rng: random.Random, persone: Persone) -> str:
    kw = rng.choice(PAROLE_CHIAVE[Campo.PERSONE][persone])
    return f"mi dicono che {kw}"


def _rumore(rng: random.Random, testo: str) -> str:
    """Applica le imperfezioni tipiche del parlato. Ogni trasformazione ha una probabilità fissa."""
    if rng.random() < 0.3:
        testo = testo.lower()
    if rng.random() < 0.3:
        m = re.search(r"\. (\w)", testo)
        if m:
            riempitivo = rng.choice(RIEMPITIVI)
            testo = testo[: m.start()] + f" {riempitivo}, " + m.group(1).lower() + testo[m.end():]
    if rng.random() < 0.2:
        testo = testo.replace("piano", "p.")
    if rng.random() < 0.3:
        testo = testo.rstrip(".")
    return testo


def genera_record(rng: random.Random, idx: int) -> dict:
    edificio = rng.choice(list(TipoEdificio))
    piano = 0 if edificio is TipoEdificio.BOSCO else rng.randint(1, 6)
    sostanze = rng.choice(list(SostanzePericolose))
    persone = rng.choice(list(Persone))
    meteo = rng.choice(list(Meteo))

    apertura = rng.choice(APERTURE)
    frasi = [
        f"{apertura} {_frase_edificio(rng, edificio, piano)}",
        _frase_sostanze(rng, sostanze).capitalize(),
        _frase_persone(rng, persone).capitalize(),
        rng.choice(FRASI_METEO[meteo]).capitalize(),
    ]
    testo = _rumore(rng, ". ".join(frasi) + ".")

    return {
        "id": f"c{idx:05d}",
        "testo": testo,
        "tipo_edificio": edificio.value,
        "piano": piano,
        "sostanze_pericolose": sostanze.value,
        "persone": persone.value,
        "meteo": meteo.value,
    }


def genera(n: int, seme: int) -> list[dict]:
    rng = random.Random(seme)
    return [genera_record(rng, i) for i in range(n)]


def scrivi_csv(records: list[dict], path: Path) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    with path.open("w", newline="", encoding="utf-8") as f:
        writer = csv.DictWriter(f, fieldnames=list(records[0].keys()))
        writer.writeheader()
        writer.writerows(records)


def copertura(records: list[dict]) -> dict[str, Counter]:
    """Conteggio dei valori per campo: serve a verificare che ogni etichetta compaia nel dataset."""
    campi = ["tipo_edificio", "sostanze_pericolose", "persone", "meteo"]
    return {c: Counter(r[c] for r in records) for c in campi}


if __name__ == "__main__":
    records = genera(config.N_TESTI_SINTETICI, config.SEME)
    out = config.DATA_DIR / "dataset_sintetico.csv"
    scrivi_csv(records, out)
    print(f"Scritti {len(records)} record in {out}")
    for campo, conteggi in copertura(records).items():
        print(f"  {campo}: {dict(conteggi)}")

"""Validazione del gold set e dell'estrattore NLP.

1. Controllo di integrità del file gold_set.csv: colonne, valori ammessi, id unici.
2. Valutazione di estrai_campi() sul gold set: accuratezza, precisione, recall,
   F1 macro e matrice di confusione per ogni campo.

"""

import csv
import json
import sys
from pathlib import Path

ROOT = Path(__file__).resolve().parents[1]
sys.path.insert(0, str(ROOT))
sys.path.insert(0, str(ROOT / "src"))

import config  # noqa: E402
from domain import Meteo, Persone, SostanzePericolose, TipoEdificio  # noqa: E402
from nlp_extract import estrai_campi  # noqa: E402
from sklearn.metrics import (  # noqa: E402
    accuracy_score,
    confusion_matrix,
    precision_recall_fscore_support,
)

COLONNE = ["id", "testo", "tipo_edificio", "piano", "sostanze_pericolose", "persone", "meteo"]

VALORI_AMMESSI = {
    "tipo_edificio": {e.value for e in TipoEdificio},
    "sostanze_pericolose": {e.value for e in SostanzePericolose},
    "persone": {e.value for e in Persone},
    "meteo": {e.value for e in Meteo},
}
CAMPI_CATEGORICI = list(VALORI_AMMESSI)
ETICHETTA_ASSENTE = "nessuno"  # quando l'estrattore non riconosce il campo


def leggi(percorso: Path) -> list[dict]:
    with percorso.open(encoding="utf-8") as f:
        return list(csv.DictReader(f))


def controlla_integrita(righe: list[dict]) -> list[str]:
    errori = []
    if not righe:
        return ["file vuoto"]
    if set(righe[0].keys()) != set(COLONNE):
        errori.append(f"colonne attese {COLONNE}, trovate {list(righe[0].keys())}")
    ids = [r["id"] for r in righe]
    if len(ids) != len(set(ids)):
        errori.append("id duplicati")
    for r in righe:
        if not r["testo"].strip():
            errori.append(f"{r['id']}: testo vuoto")
        if not r["piano"].isdigit() or int(r["piano"]) > 6:
            errori.append(f"{r['id']}: piano={r['piano']!r} non valido")
        for campo, ammessi in VALORI_AMMESSI.items():
            if r[campo] not in ammessi:
                errori.append(f"{r['id']}: {campo}={r[campo]!r} non ammesso")
    return errori


def valuta(righe: list[dict]) -> tuple[dict, list[dict]]:
    predizioni = [estrai_campi(r["testo"]) for r in righe]
    risultati = {}
    errori = []

    # Piano: valore intero, quindi basta l'accuratezza esatta.
    ok = [int(p["piano"]) == int(r["piano"]) for p, r in zip(predizioni, righe)]
    risultati["piano"] = {"accuracy": sum(ok) / len(ok)}
    for p, r, corretto in zip(predizioni, righe, ok):
        if not corretto:
            errori.append({"id": r["id"], "campo": "piano", "vero": r["piano"],
                           "predetto": p["piano"], "testo": r["testo"]})

    for campo in CAMPI_CATEGORICI:
        veri = [r[campo] for r in righe]
        pred = [p[campo] if p[campo] is not None else ETICHETTA_ASSENTE for p in predizioni]
        etichette = sorted(VALORI_AMMESSI[campo])
        precisione, recall, f1, _ = precision_recall_fscore_support(
            veri, pred, labels=etichette, average="macro", zero_division=0
        )
        matrice = confusion_matrix(veri, pred, labels=etichette + [ETICHETTA_ASSENTE])
        risultati[campo] = {
            "accuracy": accuracy_score(veri, pred),
            "precision_macro": precisione,
            "recall_macro": recall,
            "f1_macro": f1,
            "matrice_confusione": {
                "etichette": etichette + [ETICHETTA_ASSENTE],
                "matrice": matrice.tolist(),
            },
        }
        for p, r, v, q in zip(predizioni, righe, veri, pred):
            if v != q:
                errori.append({"id": r["id"], "campo": campo, "vero": v,
                               "predetto": q, "testo": r["testo"]})

    return risultati, errori


if __name__ == "__main__":
    # Uso: python src/validate.py [gold|dev]   (default: gold)
    nome = sys.argv[1] if len(sys.argv) > 1 else "gold"
    righe = leggi(config.DATA_DIR / f"{nome}_set.csv")

    problemi = controlla_integrita(righe)
    if problemi:
        print("Errori di integrità nel gold set:")
        for p in problemi[:20]:
            print(" -", p)
        sys.exit(1)
    print(f"Integrità OK: {len(righe)} testi.")

    risultati, errori = valuta(righe)

    config.RESULTS_DIR.mkdir(parents=True, exist_ok=True)
    with (config.RESULTS_DIR / f"metrics_nlp_{nome}.json").open("w", encoding="utf-8") as f:
        json.dump(risultati, f, ensure_ascii=False, indent=2)
    with (config.RESULTS_DIR / f"errori_nlp_{nome}.csv").open("w", newline="", encoding="utf-8") as f:
        writer = csv.DictWriter(f, fieldnames=["id", "campo", "vero", "predetto", "testo"])
        writer.writeheader()
        writer.writerows(errori)

    print(f"\n{'campo':22s} {'accuracy':>9s} {'F1 macro':>9s}")
    for campo, m in risultati.items():
        f1 = m.get("f1_macro", float("nan"))
        print(f"{campo:22s} {m['accuracy']:9.3f} {f1:9.3f}")
    print(f"\nInsieme: {nome}. Errori totali: {len(errori)} (dettaglio in results/errori_nlp_{nome}.csv)")

==> ./src/nlp_extract.py <==
"""Estrazione dei campi di una chiamata dal solo testo (regole e regex).

Il lessico di questo modulo è definito qui, separato da PAROLE_CHIAVE di
domain.py che il generatore usa per produrre i testi. Così il risultato non
dipende dalle stesse frasi usate per generare il dataset.

Il gold set (data/gold_set.csv) è stato usato anche per analizzare gli errori,
quindi il suo risultato non è più completamente indipendente: va dichiarato.
"""

import csv
import re
import sys
from pathlib import Path

ROOT = Path(__file__).resolve().parents[1]
sys.path.insert(0, str(ROOT))
sys.path.insert(0, str(ROOT / "src"))

from domain import Meteo, Persone, SostanzePericolose, TipoEdificio  # noqa: E402

ORDINALI = {"primo": 1, "secondo": 2, "terzo": 3, "quarto": 4, "quinto": 5, "sesto": 6}

# Radici (non frasi intere) per riconoscere il tipo di edificio.
RADICI_EDIFICIO = {
    TipoEdificio.RESIDENZIALE: ["palazzin", "palazz", "condomin", "appartament", "abitazion", "villett", "casa"],
    TipoEdificio.INDUSTRIALE: ["capannon", "stabiliment", "deposit", "officin", "magazzin", "fabbric"],
    TipoEdificio.BOSCO: ["bosc", "sterpaglie", "pineta"],
}

# Radici che indicano una sostanza pericolosa.
RADICI_SOSTANZE = [
    "bombol", "serbatoi", "vernic", "solvent", "acid", "gas",
    "benzin", "tanic", "gpl", "idrogen", "ossigen", "cloro", "propan",
]

# Negazioni: parole generiche oppure "non c'è / non ci sono / non risulta".
NEGAZIONE = re.compile(r"\b(nessun\w*|niente|nulla)\b|\bnon (c'è|ci sono|ci sia|ci siano|risulta)\b")

# Persone: l'ordine di priorità conta. L'incertezza prevale, poi le assenze, poi le conferme.
PATTERN_INCERTE = [r"non sappiamo", r"non si sa", r"forse", r"potrebbe esserci", r"pare ci sia", r"non è sicuro"]
PATTERN_ASSENTI = [
    r"non c'è nessuno",
    r"nessuno dentro",
    r"tutti (sono )?(usciti|fuori)",
    r"edificio (è|risulta) (vuoto|sgombro)",
]
# Negazione diretta di una persona bloccata: "nessuno è intrappolato", "nessuno è rimasto dentro".
PATTERN_NEGATE_CONFERMATE = re.compile(r"\bnessun\w* (è |sono )?(intrappolat|bloccat|rimast)")
PATTERN_CONFERMATE = [r"intrappolat", r"bloccat", r"rimast\w* dentro", r"non riesc\w* a (uscire|scendere)"]

# Meteo: calma prima di vento, altrimenti "non tira vento" diventerebbe vento forte.
PATTERN_CALMO = re.compile(
    r"aria (calma|ferma)|tempo (stabile|calmo)|calm|non (c'è|tira|ci sono|ci sia) vento|niente vento"
)


def _normalizza(testo: str) -> str:
    t = testo.lower().replace("’", "'")
    t = re.sub(r"\bp\.", "piano", t)  # abbreviazione del parlato
    return re.sub(r"\s+", " ", t)


def _frasi(t: str) -> list[str]:
    return [f for f in re.split(r"[.!?]+", t) if f.strip()]


def _piano(t: str) -> int:
    """Piano come intero. Restituisce 0 se non è indicato (es. bosco)."""
    m = re.search(r"\b(\d+|" + "|".join(ORDINALI) + r")\s*(?:°\s*)?piano", t)
    if not m:
        return 0
    v = m.group(1)
    return int(v) if v.isdigit() else ORDINALI[v]


def _edificio(t: str) -> str | None:
    for tipo, radici in RADICI_EDIFICIO.items():
        if any(r in t for r in radici):
            return tipo.value
    return None


def _sostanze(t: str) -> str:
    """Una frase positiva è 'si' solo se non è negata. Il default è 'no'."""
    for f in _frasi(t):
        contiene_sostanza = any(r in f for r in RADICI_SOSTANZE) or "sostanz" in f or "rischio chimico" in f
        if not contiene_sostanza:
            continue
        if NEGAZIONE.search(f):
            return SostanzePericolose.NO.value
        if any(r in f for r in RADICI_SOSTANZE):
            return SostanzePericolose.SI.value
    return SostanzePericolose.NO.value


def _persone(t: str) -> str | None:
    if any(re.search(p, t) for p in PATTERN_INCERTE):
        return Persone.INCERTE.value
    if PATTERN_NEGATE_CONFERMATE.search(t):
        return Persone.ASSENTI.value
    if any(re.search(p, t) for p in PATTERN_ASSENTI):
        return Persone.ASSENTI.value
    if any(re.search(p, t) for p in PATTERN_CONFERMATE):
        return Persone.CONFERMATE.value
    return None


def _meteo(t: str) -> str | None:
    if PATTERN_CALMO.search(t):
        return Meteo.CALMO.value
    if "vento" in t:
        return Meteo.VENTO_FORTE.value
    return None


def estrai_campi(testo: str) -> dict:
    """Ricava tutti i campi dal testo. I campi non riconosciuti restano None."""
    t = _normalizza(testo)
    return {
        "tipo_edificio": _edificio(t),
        "piano": _piano(t),
        "sostanze_pericolose": _sostanze(t),
        "persone": _persone(t),
        "meteo": _meteo(t),
    }


if __name__ == "__main__":
    # Verifica rapida sul dataset sintetico. ATTENZIONE: questo numero è ottimistico,
    # perché le regole sono state scritte guardando lo stesso tipo di testi.
    # La valutazione vera si fa su gold set in validate.py.
    percorso = ROOT / "data" / "dataset_sintetico.csv"
    campi = ["tipo_edificio", "piano", "sostanze_pericolose", "persone", "meteo"]
    corretti = {c: 0 for c in campi}
    righe = 0
    with percorso.open(encoding="utf-8") as f:
        for r in csv.DictReader(f):
            righe += 1
            pred = estrai_campi(r["testo"])
            for c in campi:
                if str(pred[c]) == str(r[c]) or (c == "piano" and int(r[c]) == pred[c]):
                    corretti[c] += 1
    for c in campi:
        print(f"{c}: {corretti[c] / righe:.3f}")

"""Vocabolario unico del dominio SO-VVF-NEXT.

Fonte di verità per generatore di dataset, adattatore NLP, knowledge base
Prolog, rete bayesiana, ricerca nello spazio degli stati e ML. Ogni modulo
importa da qui, così le etichette non possono divergere tra un componente e l'altro.

"""

from enum import Enum


class TipoEdificio(str, Enum):
    RESIDENZIALE = "residenziale"
    INDUSTRIALE = "industriale"
    BOSCO = "bosco"


class SostanzePericolose(str, Enum):
    SI = "si"
    NO = "no"


class Gravita(str, Enum):
    """Etichetta di gravità a tre livelli. Le regole che la definiscono vanno dichiarate
    in knowledge_base/kb.pl: la definizione è una regola di dominio esplicita, non un'etichetta libera."""
    CRITICO = "critico"
    ALTO = "alto"
    BASSO = "basso"


class VelocitaFuoco(str, Enum):
    ALTA = "alta"
    MEDIA = "media"
    BASSA = "bassa"


class Persone(str, Enum):
    CONFERMATE = "confermate"
    INCERTE = "incerte"
    ASSENTI = "assenti"


class Meteo(str, Enum):
    VENTO_FORTE = "vento_forte"
    CALMO = "calmo"


class TipoMezzo(str, Enum):
    AUTOPOMPA = "autopompa"          # APS / autopompa serbatoio
    AUTOSCALA = "autoscala"
    NUCLEO_NBCR = "nucleo_nbcr"      # rischio chimico, biologico, radiologico
    CANADAIR = "canadair"            # incendi boschivi


class Equipaggiamento(str, Enum):
    TUTA_HAZMAT = "tuta_hazmat"
    RILEVATORE_GAS = "rilevatore_gas"
    AUTORESPIRATORE = "autorespiratore"


class Campo(str, Enum):
    """Campi estratti dal testo della chiamata. Ogni campo ha un proprio enum di valori."""
    TIPO_EDIFICIO = "tipo_edificio"
    SOSTANZE_PERICOLOSE = "sostanze_pericolose"
    PERSONE = "persone"


# Parole chiave usate dal generatore e dall'estrattore NLP.
# Struttura: Campo -> valore del campo -> lista di espressioni italiane.
# Tutte le chiavi interne sono membri degli enum sopra, mai stringhe libere.
# Il gold set manuale NON usa solo queste parole, per evitare un test circolare.
PAROLE_CHIAVE: dict[Campo, dict[Enum, list[str]]] = {
    Campo.TIPO_EDIFICIO: {
        TipoEdificio.RESIDENZIALE: ["una palazzina", "un condominio", "un appartamento"],
        TipoEdificio.INDUSTRIALE: ["un capannone", "uno stabilimento", "un deposito"],
        TipoEdificio.BOSCO: ["un bosco", "delle sterpaglie", "una pineta"],
    },
    # Le espressioni sono frasi complete, così il generatore le inserisce senza errori grammaticali.
    # L'estrattore NLP cercherà le stesse radici, non le frasi intere.
    Campo.SOSTANZE_PERICOLOSE: {
        SostanzePericolose.SI: ["bombole di gas", "un serbatoio", "delle vernici", "dei solventi", "dell'acido"],
        SostanzePericolose.NO: ["nessuna sostanza pericolosa", "niente sostanze pericolose", "nessun rischio chimico"],
    },
    Campo.PERSONE: {
        Persone.CONFERMATE: ["ci sono persone intrappolate", "c'è qualcuno bloccato", "qualcuno non riesce a uscire"],
        Persone.INCERTE: ["non sappiamo se ci sia qualcuno", "forse c'è qualcuno dentro", "potrebbe esserci qualcuno"],
        Persone.ASSENTI: ["non c'è nessuno dentro", "tutti sono usciti", "l'edificio è vuoto"],
    },
}

# Soglia di altezza (in piani) sopra cui serve l'autoscala. Assunzione dichiarata.
SOGLIA_PIANI_AUTOSCALA = 4

# Soglia di probabilità per trasformare la distribuzione BN in una decisione.
# Assunzione dichiarata: P(Critico) > soglia => gravità operativa "critica".
SOGLIA_PROB_CRITICO = 0.7

# Velocità massima ammessa sulla griglia (unità arbitraria di distanza per unità di tempo).
# Usata per h(n) = distanza_euclidea / V_MAX_GRIGLIA, con V_MAX_GRIGLIA = velocità massima di qualunque arco.
V_MAX_GRIGLIA = 1.0
